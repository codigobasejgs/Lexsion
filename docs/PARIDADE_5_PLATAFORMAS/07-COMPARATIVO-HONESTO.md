# 07 — Comparativo honesto

Coluna **Referência** = o que a página pública afirma (alegação comercial, salvo indicação). Coluna **LexSion** = o que o código do HEAD final faz, com teste. Não houve acesso a áreas logadas: a paridade é por **resultado útil**, não "100% igual".

# Guia rápido — SIWILTEC (versão de demonstração)

Tudo o que você vê aqui é **de mentira, para treinar**. Nenhuma mensagem, cobrança ou assinatura é enviada de verdade.

## 1. Entrar
1. Abra o endereço da SIWILTEC.
2. Toque no seu perfil (por exemplo, “Advogado(a)”) e em **Entrar como…**.

## 2. Onde está cada coisa
- **Meu dia**: o que precisa da sua atenção hoje, do mais urgente ao menos urgente.
- **Lupa no topo**: procura clientes, casos e ajuda. No computador, também `Ctrl + K`.
- **Ponto de interrogação no topo**: “Como usar esta tela?” — abre o passo a passo e o tour desta tela.
- **Sino**: avisos do escritório.
- No celular, a barra de baixo tem Meu dia, Conversas, Agenda e **Mais** (todo o resto).

## 3. Tarefas do dia a dia
| Quero… | Vá em… | Toque em… |
|---|---|---|
| Cadastrar um cliente | Clientes | **Novo cliente** → **Salvar cliente** |
| Registrar um interessado | Funil (CRM) | **Novo lead** |
| Fazer a triagem | ficha do lead | responder as perguntas → **Registrar triagem e encaminhar** |
| Responder no WhatsApp | Conversas | **Assumir atendimento** → escrever → **Enviar** |
| Pedir um documento | Documentos → Solicitações | **Solicitar documento** |
| Registrar um prazo | Prazos | **Novo prazo** → **Registrar prazo proposto** (um(a) advogado(a) confirma) |
| Marcar perícia ou audiência | Agenda | **Novo compromisso** |
| Dar baixa num pagamento | Financeiro → A receber | **Registrar pagamento** → **Confirmar baixa** |
| Emitir recibo | detalhe da parcela paga | **Recibo** |
| Baixar petição em Word | Minutas → minuta aprovada | **Word (.docx)** |
| Atualizar o cliente | Caso → Portal do cliente | escrever → **Salvar rascunho** → advogado(a) **Publicar no portal** |

## 4. Se algo der errado
- Mensagem em vermelho diz o que corrigir.
- Lançou errado no financeiro? Use **Estornar** — nada é apagado.
- Para recomeçar a demonstração: Configurações → Dados e LGPD → **Restaurar demonstração**.
- Aviso amarelo “Armazenamento do navegador indisponível”: o que você fizer some ao fechar a aba (navegação privada).

# Roteiros de demonstração

Antes: Configurações → Dados e LGPD → “Restaurar demonstração”. Cada roteiro dura 3–5 minutos.

## 1. Da campanha ao contrato (Administrador)
1. Funil (CRM) → “Simular formulário de campanha” → enviar com autorização. Mostrar origem confirmada (UTM).
2. “Ver conversa” → “Assumir atendimento”.
3. Ficha do lead → “Converter em cliente” (mostrar detecção de duplicado com o mesmo CPF).
4. Propostas → “Revisão bancária — Ronaldo” → “Abrir contrato” → “Simular assinatura” (contratante e contratada). Testemunha opcional não bloqueia. Parcelas geradas uma vez.

## 2. Planejamento previdenciário (Advogado)
Previdenciário → análise do João → linha do tempo (trecho do CNIS) → marcar pendência → “Resultado desatualizado” → “Marcar exemplo como revisado”.

## 3. Prazo à agenda (Advogado)
Prazos → “Novo prazo” (mostrar memória de contagem e feriado de 02/11) → “Conferir e confirmar” → aparece na Agenda e no Meu dia.

## 4. Financeiro realista (Financeiro)
A receber → João (entrada + 7 parcelas em datas próprias) → baixa parcial de R$ 150,00 → “Renegociar saldo” → “Recibo” → Conciliação (tarifa, duplicidade, remetente desconhecido).

## 5. Queda do WhatsApp (Administrador)
Integrações → Evolution → “Simular desconexão” → responder uma conversa (fica “Na fila”) → “Simular reconexão” (1 reenviada, sem duplicar).

## 6. Aprender sozinho (Atendimento, no celular)
Academia → tour “Primeiro acesso” → “Pausar” → voltar e “Retomar” → Central de ajuda → “Cadastrar cliente” com prints.

## 7. Portal do cliente (Cliente)
Entrar como cliente → status em linguagem simples → enviar documento → “Fazer o tour da área do cliente”.
